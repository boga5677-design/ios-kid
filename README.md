# PetLingo Kids iOS / iPadOS

SwiftUI 原生版本，依 Android `kid-main(3)` 的 PetLingo Kids 6.0 內容移植。

- iPhone + iPad，iPad 使用更寬的自適應版面。
- 三隻毛孩素材沿用原專案。
- 224 個幼兒單字（123 個生活主題 + 0–100 數字）。
- 20 關闖關、單字學習、AI 發音、每日任務、寵物成長、家長模式、成就。
- 發音模式：示範播放完成後等待 0.5 秒才開啟麥克風，避免示範音被辨識。
- iOS 17+。

## GitHub Actions
Push 到 GitHub 後可執行 **Build PetLingo Kids iOS**，會產出 Simulator `.app` 壓縮檔。真機 IPA / TestFlight 仍需 Apple Developer 簽章。
